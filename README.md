# KanakoCharacterMemo

オリジナルキャラクターを、画像・名前・特徴メモの3項目で気軽に残すためのカード型Webアプリです。

## 現在の機能

- キャラクターカード一覧
- キャラ画像の追加
- 名前
- 特徴メモ
- 編集・削除
- 名前／特徴から検索
- iPad・スマートフォン向けレスポンシブ表示
- IndexedDBによる端末内保存

## 保存について

キャラクターデータと画像は、現在はブラウザのIndexedDBに保存します。
同じ端末・同じブラウザでは保持されますが、別端末には自動同期されません。

今後、シリーズ管理や追加プロパティ、クラウド保存などを段階的に追加する想定です。
